# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses

## [Unreleased]

### Added

- `weirdnet-ext-proto`: the `weirdnet.ext.v1` contract (handshake, events, calls, logs, health).
- `weirdnet-ext`: signed packages, install and update rules with author pinning, grants, the Linux (Landlock and seccomp) and macOS sandboxes, the broker and the supervisor.
- `weirdnet-ext-sdk`: connect, call, log, report health, and handle events from an extension.
